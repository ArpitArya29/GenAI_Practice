# 🤖 GenAI Practice

A hands-on repository documenting my learning and experimentation with **Generative AI, Large Language Models (LLMs), and modern AI application concepts**.

This repository contains practical implementations and experiments focused on understanding how GenAI systems work beyond simply using AI APIs.

---

## 📚 What I'm Exploring

### 🧠 LLM Fundamentals
- Basic interaction with language models
- Model inputs and outputs
- Tokenization and token encoding/decoding

### ✍️ Prompt Engineering
- Prompting techniques
- Structured prompting
- Working with model instructions
- Experimenting with tool usage and model interactions

### 🔧 Tool Usage
- Passing tools to language models
- Understanding tool calling
- Connecting models with external functionality

### 🔍 Retrieval-Augmented Generation (RAG)
- Understanding the RAG architecture
- Document retrieval concepts
- Connecting retrieved context with LLM responses
- Building basic RAG workflows
