# What is AI?
Input -> Output
- An Engine which can accept the input as the natural language for the humans, and gives them an output
- Instead of giving any technical terms of input, any kind of user (developer, students or a normal person, could use AI for their use-case)

## Myths about genAI
- Most of the person thinks that we need to have a good hands on engineering experience of ML, Deep Learning and more advanced concepts
- The genAI developer, could have the knowledge of these things, not necessarily, these developers could focus on the engineering side of the application using something that is built over AI (AI Models)
- The developers have different models, which can be used by them for developing the AI applications
- Taking the analogy of Car (Body + engine), the engine that is used is the AI models, and the car that is created, the functionality, the working and using the engine, all assembled, is the Car - the work of application developer

### The better approach for an application developer
- Knows the functionality and working of the Engine part, then use that knowledge for developing the application part
